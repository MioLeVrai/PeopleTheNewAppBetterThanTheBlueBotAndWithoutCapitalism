# PEOPLE — À LIRE

L'application de ce dossier s'appelle **People**.

## Si tu vois encore "Discord 2"

Tu es en train d'ouvrir une ancienne copie ou un ancien serveur.
N'utilise plus l'ancien dossier `discord2_simple`.

Dézippe ce projet dans un nouveau dossier, par exemple :

`D:\crack\Discord 2`

Puis utilise uniquement les fichiers de ce dossier.

Pour tester en local :
- double-clique sur `LANCER_PEOPLE_LOCAL.bat`

Pour obtenir le lien public fixe :
- double-clique sur `METTRE_PEOPLE_EN_LIGNE.bat`
- la première fois, il peut installer Git et GitHub CLI
- relance-le après une installation si le programme te le demande
- connecte-toi à GitHub dans le navigateur
- il envoie le projet sur GitHub et ouvre Render
- sur Render, approuve le déploiement

URL Render visée :

`https://peoplethenewappbetterthanthebluebotandwithoutcapitalism.onrender.com`

Cette URL n'existe réellement qu'une fois le service créé et le premier déploiement terminé.

Si une ancienne version reste affichée après un nouveau déploiement, fais `Ctrl+F5` dans le navigateur.
