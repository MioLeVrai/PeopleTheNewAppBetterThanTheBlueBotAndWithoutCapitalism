PEOPLE - bouton "Rejoindre" pour les appels MP persistants

1. Mets ces fichiers dans le dossier principal de People, a cote de server.js :
   - CORRIGER_BOUTON_REJOINDRE_MP.bat
   - people-dm-join-label.patch

2. Lance CORRIGER_BOUTON_REJOINDRE_MP.bat.

Le correctif ne modifie que public/people-dm-calls.js.
Il cree une sauvegarde avant modification.

Comportement :
- si tu as quitte un appel MP mais que l'autre personne est encore dedans, le bouton de ce MP affiche "Rejoindre" ;
- si tu recois/retrouves une room MP encore active, le bouton affiche aussi "Rejoindre" ;
- quand la room est vraiment fermee (plus personne ou timeout 3 min), le bouton revient a "Appeler" ;
- si tu changes de conversation MP, le libelle est recalcule pour la conversation affichee.
